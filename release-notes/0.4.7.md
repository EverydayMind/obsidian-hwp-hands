## What's new

- **Other plugins can honor the AI-private list.** A new public `api.privacy.isBlocked(path)` check lets Verbex and the versions of KorDoc Transform that support it skip private documents, including a document's `.index.md` note. If the list is damaged or needs review, it fails closed for HWP documents and their index notes only, so other notes stay reachable. Honoring it is voluntary for the caller. The tool definitions did not change, so no re-approval is needed in Verbex.
- **Calmer "still working" notice.** It now appears only for operations you can cancel, after 1.5 seconds, and names the operation (for example saving/exporting or rendering).
- **Status bar.** The unsaved-documents item starts hidden instead of flashing on load.
- **Editor toolbar.** The duplicate "Fit width" and "Fit page" buttons under the editor were removed; the zoom menu offers both.
- **AI privacy notice.** The wording now says that Verbex and KorDoc Transform versions that honor the list also skip the document and its index note, and that other tools can still read the file directly.
