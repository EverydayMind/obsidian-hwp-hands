## What's new

- **AI tool keywords work across languages.** The keywords that expose the editing tools to the host (for example Verbex) now carry Korean and English words in any app language, so a Korean request in an English Obsidian — and the reverse — reaches the editing tools. The tool definitions changed; approve HWP Hands again in the host after updating.
- **Cleaner command palette.** Duplicate entries (new document, open document, recover input, collapse menus) and entries that were always disabled are gone. Zoom, header/footer template and lowercase entries now carry a category or page scope, so every name is distinct.
- **English UI wording.** "Alignment" (was "Sort"), "Both pages" (was "Justified"), and sentence-case buttons.
- **Settings.** Diagnostics, IME and screen reader compatibility, and the plugin API note moved under "Advanced and diagnostics". The "Custom settings" choice, which did nothing, was removed.
- **Dialogs.** The new document dialog has a Cancel button, folder suggestions and a hint. The save prompt after closing a tab offers "Keep editing".
- **AI privacy notice.** It now states that other plugins and tools can still read the file and its index note directly.
