## What's new

- **Collaborative editing Skill for AI hosts.** HWP Hands now ships a Skill that teaches an AI host how to read and edit HWP/HWPX documents together with you in the working copy: wording, paragraphs, tables, fill-in fields and formatting, with saving, copies and new documents kept behind separate approvals. Hosts that support plugin Skills (such as the latest Verbex) can use it; it is currently written in Korean.
- **Settings tell you whether your AI host reads plugin Skills.** The settings tab now says whether an enabled AI host can read this plugin's Skills, and suggests updating Verbex if none can.
- **AI-private list for hosts.** The AI-private check is now also offered to hosts through the new host capabilities channel, using the same rule as the public `api.privacy.isBlocked(path)`, which stays available for older Verbex versions.
- **Approve once after updating.** The tool definitions did not change, but as after every update, Verbex asks you to approve HWP Hands again before the agent can use its tools.
